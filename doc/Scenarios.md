# Scenarios

### Problem Description
Hans's team faces the issue that compiling the already developed software can take up to two hours because, with each new compilation, the code that is no longer being developed, known as "legacy code", is also being compiled. Hans now wants to identify which files belong to the "legacy code." Once this "legacy code" is found, it can be moved so that it is not included in the compilation process. This reduces the compilation time, significantly decreasing the development time.

### Scenario 1
Hans uses the tool to display an interactive treemap that shows which files are changed most frequently or not at all. Hans can click through the individual path levels.
